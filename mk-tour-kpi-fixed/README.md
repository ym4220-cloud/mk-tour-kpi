# MK투어 KPI — 스타일 표시 수정본

## 먼저 확인하세요

- **`public/preview.html`** 을 더블클릭하면 인터넷/서버 없이도 딥그린·골드 좌측 대시보드 디자인을 **예시 데이터**로 볼 수 있습니다. 미리보기에서는 로그인, 저장, 등록이 동작하지 않습니다.
- **`public/index.html`** 은 실제 로그인/DB 연동용 홈페이지입니다. CSS를 HTML 내부에 포함해 파일 경로 오류로 인한 무스타일 표시를 방지했습니다. 다만 `file:///`에서 열면 API 연결이 되지 않아 로그인할 수 없습니다.
- 실제 운영은 프로젝트 전체를 Node.js/Express + PostgreSQL 서버에 배포한 뒤 `https://...` 주소로 접속하세요.

## 오류 원인

이전 HTML의 `/style.css`, `/app.js`는 웹서버 최상위 경로를 의미합니다. `file:///C:/.../index.html`로 열면 `C:/style.css` 등 엉뚱한 경로를 찾아 스타일과 스크립트가 누락됩니다. 이번 버전은 CSS를 인라인으로 넣고 JS 경로를 상대 경로로 변경했습니다.

## 배포

`render.yaml` 및 `.env.example`을 참조하세요. 관리자 비밀번호는 12자 이상으로 설정하고 실제 비밀번호를 GitHub에 올리지 마세요. 기존 온라인 DB를 사용하는 경우 반드시 백업한 뒤 적용하세요.
